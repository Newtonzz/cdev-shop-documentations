# cDev — headless storefront

A self-contained storefront generated by BLDR. It talks to the Tebex Headless
API from the browser, so it can be hosted anywhere that serves static files:
Vercel, Netlify, Cloudflare Pages, GitHub Pages, or your own nginx.

## Deploy

Upload the contents of this folder as-is. There is no build step.

## Configuration

Your public webstore token is already baked into index.html.

The token is public by design — the Headless API exposes only what your
storefront already shows. Your secret key is never included here.

## Checkout

Adding a package creates a Tebex basket and stores its identifier in the
browser. Checkout sends the customer to the URL Tebex returns for that basket,
so payment, tax and compliance stay with Tebex.
